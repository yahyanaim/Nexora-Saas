SaaS Starter · Complete Setup Guide

This documentation provides a comprehensive step-by-step guide to set up and run the Volix project on your local machine. Please read it thoroughly before starting, and refer back whenever needed.

Before you begin: Make sure you have Node.js (version 20 or later) and MongoDB (local or Atlas) installed on your system.

Requirements

To run the project successfully, the following tools must be installed on your machine:

  • Node.js — Version 20 or newer
    Download from nodejs.org
  • npm — Comes automatically with Node.js
  • MongoDB — Local server or free MongoDB Atlas account
    Get a free account →
Note: If using MongoDB Atlas, make sure to add your machine's IP address to the Network Access whitelist in your Atlas dashboard.

Setup Instructions

Follow these steps in order to run the project for the first time.

Step 1: Extract the Files

Extract the ZIP archive you received after purchase, and open the extracted folder in your code editor or terminal.

Step 2: Install Dependencies

Run the following command in your terminal inside the project folder: 

npm install

This command reads the package.json file and installs all required libraries.

Step 3: Set Up Environment (One-Time Only)

Run the command below to automatically create the .env file and set up the database with an Admin account: 

npm run seed

This command will:

  • Create a .env file with default values if it doesn't exist
  • Add any missing variables if the file already exists
  • Create an Admin account in the database
Important: This command only needs to be run once during initial setup. After that, you only need npm run dev to start the application.

Step 4: Customize the Environment File

Open the .env file and replace the default values with your actual credentials (database URI, Cloudinary keys, email settings, etc.).

Security Warning: Never share your .env file with anyone, and never commit it to any public repository.

Step 5: Run the Project

Start the development server using:

npm run dev

Once the terminal shows that the server is running, open your browser and go to:
http://localhost:3000

Step 6: First Login

The Seed script has automatically created an Admin account with the following credentials:

  • Email: admin@volix.saas.com
  • Username: volixadmin
  • Password: Aa123456
Very Important: After your first login, change the password immediately from within the dashboard. These are placeholder values only for testing — never use them in a production environment.

Environment Variables Explained

The .env file contains all the sensitive keys and settings required by the application. Here's a detailed breakdown of each variable and where to get the actual values:

Database

Variable Description Where to Get It
MONGODB_URI MongoDB connection string Local: mongodb://localhost:27017/volix-saas
Cloud: From MongoDB Atlas dashboard → "Connect" button

Authentication (JWT)

Variable Description Where to Get It
JWT_SECRET Secret key for signing authentication tokens Generate a strong key using:
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

File Upload (Cloudinary)

Variable Description Where to Get It
CLOUDINARY_CLOUD_NAME Your Cloudinary account name From Cloudinary Dashboard
CLOUDINARY_API_KEY API key for Cloudinary
CLOUDINARY_API_SECRET API secret (keep this very secure)
CLOUDINARY_UPLOAD_PRESET Upload preset for file uploads (optional) Cloudinary → Settings → Upload Presets
Warning: Never expose CLOUDINARY_API_SECRET in any frontend code.

Email (SMTP)

Variable Description Where to Get It
SMTP_HOST SMTP server hostname From your email service provider (e.g., smtp.gmail.com)
SMTP_PORT SMTP server port 587 (TLS) or 465 (SSL)
SMTP_USER SMTP username (email address) Your sender email address
SMTP_PASS SMTP password or App Password For Gmail: Generate from Security Settings → App Password
(Not your regular account password)
EMAIL_FROM Sender email address shown in outgoing emails e.g., no-reply@yourdomain.com

Default Admin Credentials

Variable Description Default Value
SEED_ADMIN_EMAIL Admin email address admin@volix.saas.com
SEED_ADMIN_USERNAME Admin username volixadmin
SEED_ADMIN_PASSWORD Admin password Aa123456
Critical: Change these values in .env before any production deployment, and change the password from within the application after first login.

Troubleshooting

Here are solutions to the most common issues you might encounter during setup:

1. Error: MONGODB_URI is not set

Cause: The .env file is missing or doesn't contain the MONGODB_URI variable.
Solution: Run npm run seed to auto-generate the file, or add the variable manually.

2. Garbled characters in terminal (Windows)

Cause: Character encoding issue.
Solution: Run this command in PowerShell: 

chcp 65001

3. File uploads failing

Cause: Cloudinary keys are incorrect or missing.
Solution: Verify all four Cloudinary variables in .env:

  • CLOUDINARY_CLOUD_NAME
  • CLOUDINARY_API_KEY
  • CLOUDINARY_API_SECRET
  • CLOUDINARY_UPLOAD_PRESET

4. Database connection error

Cause: MongoDB is not running locally, or the URI is incorrect.
Solution:

  • Ensure MongoDB is running on your machine.
  • If using MongoDB Atlas, add your IP address to the Network Access whitelist.
  • Verify the URI string in .env.
Pro Tip: If you encounter an issue not listed here, double-check that you've followed all steps in the correct order and that you're using the required versions mentioned in the Requirements section.
