Nexora ERP: دليل المستخدم والمرجع

Nexora نظام تخطيط موارد لشركات الخدمات (الوكالات، الاستشارات، الاستوديوهات، خدمات تقنية المعلومات). يتابع سلسلة العمل كاملة: الأشخاص ← العملاء ← المشاريع ← الساعات ← الفواتير ← التحصيل ← الربح. يشرح هذا الدليل كيفية الاستخدام لكل دور، وكل وحدة خطوة بخطوة، وقواعد العمل، ودليل المطوّر لفريق تقنية المعلومات، وخارطة الطريق.

01مرحبًا بك في Nexora

Nexora هو نظام تخطيط موارد (ERP) لشركات الخدمات. يربط بين الأشخاص الذين ينجزون العمل، والعملاء الذين يدفعون مقابله، والمشاريع التي ينتمي إليها، والساعات المبذولة فيها، ثم يحوّل كل ذلك إلى فواتير وتحصيلات وأرقام ربحية – دون جداول بيانات متفرقة.

لمن هو؟

الوكالات، مكاتب الاستشارات، استوديوهات التصميم والفيديو، شركات خدمات تقنية المعلومات، مكاتب الهندسة: كل فريق يبيع الوقت أو المشاريع أو الاشتراكات الشهرية.

ماذا يستبدل؟

جدول الساعات، أداة الفوترة المنفصلة، ملفات الموارد البشرية، قائمة «من لم يدفع بعد»، وجدول الربحية في نهاية الشهر.

ماذا تحصل؟

مكان واحد تُعتمد فيه كل ساعة وتُفوتر وتُقاس، مع تطبيق قواعد شركتك (الأسعار، الموافقات، الضرائب، الترقيم) تلقائيًا.

02تسجيل الدخول والنسخة التجريبية

  1. افتح Nexora في المتصفح (محليًا: http://localhost:3000).
  2. أدخل بريدك وكلمة المرور، أو اضغط Instant Demo Preview لاستكشاف شركات تجريبية.
  3. ستصل إلى لوحة التحكم ← التحليلات. اسمك وصورتك أعلى الشاشة؛ اضغط عليهما للملف الشخصي والأمان وتسجيل الخروج.

05الإعداد الأول (قائمة مراجعة)

  1. هوية الشركة – النظام ← إعدادات مساحة العمل ← الشركة: الاسم القانوني، ICE، الرقم الضريبي، السجل التجاري، العنوان، العملة الأساسية، بداية السنة المالية، المنطقة الزمنية، صيغة ترقيم الفواتير.
  2. القوائم: الأقسام، العطل الرسمية، أنواع الإجازات، فئات المصاريف، وسوم المهام.
  3. قواعد الموافقة: من يعتمد سجلات الوقت والإجازات والمصاريف (المدير المباشر، مدير المشروع، أو شخص محدد)، على خطوة أو خطوتين.
  4. الفريق – المؤسسة ← الموظفون ← إضافة موظف: الدور، القسم، المدير، أيام العمل، الطاقة الأسبوعية، التكلفة بالساعة وسعر الفوترة.
  5. العملاء: البيانات القانونية، عنوان الفوترة، العملة، لغة الفاتورة، مهلة الدفع، جهات الاتصال، والأسعار الخاصة.
  6. المشاريع: العميل، المدير، الفريق، التواريخ، نوع الميزانية ومبلغها، المراحل.
  7. اطلب من الفريق تسجيل ساعاته يوميًا وإرسال أسبوعه يوم الجمعة.
حدّد صيغة الترقيم والسنة المالية قبل إصدار أول فاتورة؛ الأرقام متسلسلة ولا يُعاد استخدامها أبدًا.

06دليل الموظف: يومك وأسبوعك

كل يوم (دقيقتان)

  1. شغّل المؤقت عند بدء مهمة واختر المشروع والمهمة، وأوقفه عند التبديل؛ أو استخدم التسجيل السريع.
  2. افتح المشاريع لرؤية مهامك، حدّث حالة المهمة، وأجب عن التعليقات التي ذُكرت فيها.

كل جمعة

  1. افتح سجلات الوقت وراجع الأسبوع: كل صف مشروع/مهمة وكل عمود يوم؛ الشريط العلوي يقارن مجموعك بالساعات المتوقعة.
  2. أكمل النواقص (اكتب ساعات عشرية مثل 1.5؛ يُقرّب الوقت إلى أقرب 15 دقيقة).
  3. اضغط إرسال الأسبوع؛ تُقفل الساعات وتذهب إلى المعتمِد.
  4. إذا أُعيدت الساعات فاقرأ السبب وصحّحها وأعد الإرسال.
نصيحة: «نسخ الأسبوع الماضي» ينشئ صفوف الأسبوع الماضي لتكتب الأرقام فقط.

07دليل المدير: إبقاء المشاريع على المسار

  1. الاثنين – التخطيط: التخطيط ← عبء العمل يعرض الطاقة والساعات المخططة والمسجلة لكل شخص؛ أعد التوزيع لمن تجاوز 100%.
  2. خلال الأسبوع – المتابعة: صحة المشروع تصبح «معرّض للخطر» أو «خارج المسار» عند تأخر المواعيد أو تجاوز الميزانية؛ تنبيهات عند 80% و100%.
  3. الجمعة/الاثنين – الاعتماد: اعتماد الوقت يعرض بطاقة لكل شخص وأسبوع؛ اعتمد أو أعد مع ذكر السبب.
  4. اعتمد الإجازات والمصاريف من صفحاتها.
الساعات المعتمدة هي ما سيُفوتر للعميل وما تُحسب عليه التكاليف؛ بعد فوترتها لا يمكن إعادة فتحها.

08دليل المحاسب: الفوترة ونهاية الشهر

  1. تأكد أن كل ساعات الشهر معتمدة.
  2. المالية ← فواتير العملاء ← جاهز للفوترة: الساعات المعتمدة غير المفوترة لكل عميل؛ اضغط إنشاء فاتورة.
  3. للسعر الثابت أو المرحلة أو الاشتراك أو الدفعة المقدمة أو الفاتورة الحرة استخدم فاتورة جديدة.
  4. راجع المسودة ثم أصدِر (تحصل على رقمها) ثم أرسِل.
  5. عند وصول المال: تسجيل دفعة (التاريخ، المبلغ، الطريقة، المرجع)؛ الدفعات الجزئية مسموحة.
  6. خطأ في فاتورة صادرة؟ أنشئ إشعارًا دائنًا؛ لا حذف أبدًا.
  7. صدّر الفواتير والمدفوعات CSV لبرنامج المحاسبة.
  8. أقفل الشهر من الإعدادات ← إقفال الفترة.

09دليل المدير العام: قراءة أداء الشركة

  1. افتح لوحة التحكم ← التحليلات.
  2. اختر الفترة والمقارنة (الفترة السابقة أو نفس الفترة من العام الماضي).
  3. اقرأ البطاقات الأربع: الإيراد المحقق، الهامش الإجمالي، نسبة الاستغلال، المبالغ المحصلة.
  4. استخدم جسر الإيرادات لمعرفة مصدر النمو أو التراجع، وتبويب عملاء معرضون للخطر.
  5. صفِّ حسب العميل أو الفريق، ثم حفظ كتقرير (PDF أو CSV).
  6. اسأل Victor مثلًا: «أي العملاء يتأخرون في الدفع؟»

11الموظفون

  1. اضغط إضافة موظف.
  2. أدخل الهوية، المسمى، القسم، المدير، الدور.
  3. حدد نوع التوظيف، الحالة، أيام العمل والطاقة الأسبوعية.
  4. أدخل التكلفة بالساعة وسعر الفوترة، ثم احفظ.

تغيير السعر

  1. افتح ملف الموظف.
  2. في سجل الأسعار اضغط تغيير السعر.
  3. أدخل السعر الجديد وتاريخ السريان والسبب؛ العمل السابق يحتفظ بالسعر القديم.

12العملاء

  1. اضغط إضافة عميل.
  2. الاسم، القطاع، الحالة (محتمل، نشط، مؤرشف)، مدير الحساب.
  3. البيانات القانونية: الاسم القانوني، ICE، الرقم الضريبي، عنوان الفوترة.
  4. العملة، لغة الفاتورة، مهلة الدفع، جهات الاتصال.
  5. اختياري: بطاقة أسعار – سعر خاص لشخص أو مسمى وظيفي.

أي سعر يُستخدم؟

  1. الشخص في بطاقة أسعار العميل
  2. مسماه الوظيفي في بطاقة الأسعار
  3. السعر الافتراضي للعميل
  4. سعر فوترة الموظف الساري في يوم العمل
لا يمكن حذف عميل لديه فواتير – أرشِفه بدلًا من ذلك.

15اعتماد الوقت

  1. راجع كل بطاقة: الساعات لكل مشروع ومهمة، المجموع مقابل الطاقة، القيمة القابلة للفوترة.
  2. اضغط اعتماد، أو إعادة واكتب سببًا يراه الشخص.
  3. استخدم اعتماد الكل عندما يكون كل شيء صحيحًا.
عند الاعتماد يُخزَّن سعر الفوترة والتكلفة على كل ساعة؛ تغيير الأسعار لاحقًا لا يغيّر العمل المعتمد.

16الإجازات والتخطيط

  1. اضغط طلب إجازة واختر النوع والتواريخ.
  2. يقبل المعتمِد أو يرفض.

18فواتير العملاء

إنشاء فاتورة من الساعات

  1. في جاهز للفوترة اضغط إنشاء فاتورة للعميل.
  2. اختر الساعات وطريقة تجميع الأسطر: حسب الشخص أو المهمة أو اليوم.
  3. اختر نسبة الضريبة وتاريخ الإصدار؛ تاريخ الاستحقاق يتبع مهلة العميل.
  4. تُعرض الدفعات المقدمة للخصم.
  5. أنشئ – تحصل على مسودة.

من المسودة إلى الدفع

  1. مسودة – عدّل الأسطر والضرائب والاقتطاع.
  2. إصدار – تحصل على رقم وتُقفل.
  3. إرسال.
  4. تسجيل دفعة – دفعة أو أكثر؛ يتحدث الرصيد.
  5. مدفوعة – تلقائيًا عند بلوغ الرصيد صفرًا.
الفاتورة الصادرة لا تُحذف أبدًا: أنشئ إشعارًا دائنًا. يمكن إلغاء فاتورة بلا مدفوعات فقط.

25أسئلة شائعة

لماذا لا أستطيع تعديل ساعاتي؟

لأنها مُرسلة أو معتمدة أو مُفوترة، أو اليوم داخل فترة مُقفلة. اطلب من مديرك إعادتها.

لماذا لا تحمل الفاتورة رقمًا؟

لأنها مسودة؛ الرقم يُعطى عند الإصدار، لذلك لا تترك المسودات المحذوفة فجوات.

كيف ألغي فاتورة أرسلتها؟

أنشئ إشعارًا دائنًا؛ وإن لم تُسجَّل أي دفعة يمكنك إلغاؤها.

العميل دفع جزءًا فقط.

سجّل الدفعة بالمبلغ المستلم؛ تظهر الفاتورة مدفوعة جزئيًا مع الرصيد.

تغيّر سعر – هل تتغير الفواتير القديمة؟

لا. الساعات المعتمدة تحتفظ بالسعر المثبت والفواتير الصادرة لا تتغير.

لماذا لا يرى زملائي بياناتي؟

في هذا الإصدار تُحفظ البيانات في متصفحك فقط؛ المشاركة تأتي مع نسخة الخادم.

28الفكرة الأساسية: القواعد أولًا

هذا الجزء موجّه إلى فريق تقنية المعلومات في الشركة المشترية وإلى المطورين الذين يطوّرون Nexora أو يستضيفونه.

قواعد العمل في Nexora مستقلة عن الشاشات وعن مكان تخزين البيانات. «رقم الفاتورة لا يُعاد استخدامه»، «لا اعتماد ذاتي»، «لا تجاوز للسعر الثابت» هي دوال TypeScript خالصة لا تعرف React ولا المتصفح ولا قاعدة البيانات.

قاعدة الاعتماديات: الاعتماديات تتجه إلى الداخل. الشاشات تستدعي الخطافات، والخطافات تستدعي دوال API، ودوال API تستدعي القواعد والتخزين. القواعد لا تستدعي الخارج أبدًا.

32الانتقال إلى الإنتاج

  1. الخادم وقاعدة البيانات أولًا: بناء API وفق مواصفات الواجهات، PostgreSQL مع ترحيلات، وعمود workspaceId في كل جدول، وإعادة استخدام قواعد src/lib/workforce في الخادم.
  2. استبدال جسم كل دالة في src/lib/api باستدعاء للخادم؛ الشاشات لا تتغير.
  3. المصادقة والصلاحيات: ملفات تعريف ارتباط آمنة HttpOnly، والتحقق من الدور والصلاحية في الخادم لكل طلب، ودخول موحد (Microsoft Entra ID، Google) للمؤسسات.
  4. الأمان: إبقاء حظر الوضع التجريبي، تشفير البيانات ونسخ احتياطي يومي، Dependabot، مراجعة سياسة CSP.
  5. السجلات والمراقبة: سجلات منظمة مع معرّف للطلب، Sentry للأخطاء، مراقبة التوافر.
  6. الاستضافة: Vercel أو Docker خلف Nginx/Caddy، وPostgreSQL مُدار، ونشر عبر GitHub Actions، واختيار منطقة تخزين البيانات المناسبة.
