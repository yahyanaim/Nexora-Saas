The Feature-Chunk Pattern

Every business domain resides in an isolated directory (e.g. src/components/shared/taxes-chunks/, invoices-chunks/, users-chunks/) containing its orchestrator, summary cards, column schemas, dialogs, and forms. This ensures sub-50ms HMR and zero bundle cross-contamination.

Resilient Dual-Mode Data Access

The client communicates through strongly-typed API adapters. When a microservice backend is unreachable or NEXT_PUBLIC_DEMO_MODE=true, the application automatically switches to in-memory state with full search, filter, and pagination fidelity.

★Release Readiness: Production Operations & Runbook

Deployment Architecture. Nexora SaaS is architected for zero-downtime deployment to modern edge infrastructure (Vercel Edge Network, AWS ECS, or Dockerized Kubernetes clusters).

Environment Variables Validation (Zod)

All runtime configurations are validated on startup via src/env.ts. Missing or malformed keys halt execution immediately with human-readable error messages:

  • NEXT_PUBLIC_APP_URL: Base URL for canonical routing.
  • NEXT_PUBLIC_API_URL: Endpoint for live microservice REST proxy.
  • NEXT_PUBLIC_DEMO_MODE: Toggle for deterministic demo data fallback.
  • JWT_SECRET: Cryptographic key for local token verification.

Operational Runbook & Disaster Recovery

  • Zero-Downtime Rollback: Atomic deployment slots allow instant 1-click rollback via immutable Docker images or Vercel deployment hashes.
  • Stateless Edge Ingress: Server-side routes do not maintain sticky sessions, enabling seamless horizontal auto-scaling.
  • Telemetry Monitoring: P99 latencies, cache hit ratios, and API rate limits tracked in real-time on the Overview telemetry card.

01Introduction & Scope

Purpose. Enable modern software organizations to launch and operate an enterprise-grade multi-tenant B2B SaaS platform with out-of-the-box governance, executive analytics, developer APIs, subscription lifecycles, and resilient dual-mode API execution.

In scope

  • Executive Cloud Analytics Hub with dual comparative graphs and sparklines
  • Multi-tenant workspace governance with role-based access control (RBAC)
  • Minimalist authentication suite with 2FA and session lock screen
  • Subscription tier catalog, usage metering gauges, and PDF invoices
  • Developer API keys, HMAC signed webhooks, and SOC 2 audit logs
  • Native internationalization across 9 languages via next-intl
  • Dual-Mode API layer: live REST proxy with automatic in-memory fallback

Out of scope / guardrails

  • No required live database setup: runs seamlessly on sample memory
  • No live credit card charges: billing operates in test sandbox mode
  • No proprietary vendor lock-in: standard Next.js App Router conventions
  • Client-side state does not mutate production data without explicit API config
Design principle: every integration degrades gracefully. With zero keys the app is fully usable on deterministic demo data; adding API keys lights up live REST backends with no code changes.

The interaction tier governs how reactive state flows across client-side components, network boundaries, optimistic mutations, and resilient demo stores.

1. Client State & Cache Invalidation (TanStack Query)

  • Query Key Hierarchy: Hierarchically structured cache keys (e.g. ['users', { page, limit, role, search }]) ensure targeted cache invalidation when mutations succeed.
  • Stale-While-Revalidate: Default staleTime: 5 * 60 * 1000 (5 minutes) delivers instantaneous page transitions while refreshing telemetry in the background.
  • Garbage Collection: Inactive query nodes are collected after 10 minutes to minimize browser memory footprint.

2. URL-Driven State Synchronization

  • Single Source of Truth: Table filters (role, status), search queries (?q=), and active pagination indices (?page=1) serialize directly into the browser URL via useSearchParams.
  • Deep Linking & Bookmarking: Department managers can bookmark or share direct links to exact table views without state degradation.
  • Back/Forward Cache Integrity: Browser history navigation updates table views without extra network overhead.

3. Optimistic Updates & Automatic Rollback

For high-frequency administrative operations (banning accounts, toggling staff permissions, archiving projects):

  1. Immediate Mutation: The client snapshot is saved via onMutate and the local cache updates instantly.
  2. Background Verification: The API request fires asynchronously to the server.
  3. Rollback Guard: Upon network failure or 4xx/5xx response, the previous cache snapshot is immediately restored and an explanatory toast notification is dispatched.

4. Form Validation & Mutation Lifecycles

Managed via React Hook Form paired with Zod Schema Resolvers:

  • Strict Typing: Form schemas mirror server DTOs (e.g., password minimum length, Moroccan ICE 15-digit format, tax rate percentages).
  • Interactive Feedback: Field errors render below inputs with accessible ARIA descriptions.
  • In-Flight Locking: Submit buttons disable and display animated spinners to prevent duplicate write transactions.
