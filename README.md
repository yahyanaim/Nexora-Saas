# SaaS Starter

A modern SaaS starter built with **Next.js, TypeScript, MongoDB, Tailwind CSS, and shadcn/ui**.

Volix provides a solid foundation for building and launching your SaaS application faster, with authentication, dashboard, users, subscriptions, roles & permissions, analytics, localization, themes, and more.

## Features

- Admin dashboard
- Authentication and security features
- User and staff management
- Roles and permissions
- Plans and subscriptions
- Transactions and invoices
- Projects and file management
- Analytics and reports
- 9 languages
- 8 built-in themes
- Responsive UI

## Tech Stack

- Next.js
- TypeScript
- MongoDB & Mongoose
- Tailwind CSS
- shadcn/ui
- React Query
- Zustand
- Zod
- JWT
- Nodemailer
- Cloudinary

## Quick Start

### 1. Install dependencies

```bash
npm install
```

### 2. Seed the database

```bash
npm run seed
```

### 3. Start the development server

```bash
npm run dev
```
